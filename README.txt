OPTION A – GITHUB PAGES (your current setup, repo ZN-03/gullydrs-website)
  1. Unzip this file on your laptop (right-click > Extract All).
  2. Open https://github.com/ZN-03/gullydrs-website
  3. Click "Add file" > "Upload files".
  4. Open the unzipped folder, press Ctrl+A to select everything, and drag it all into the GitHub page.
     (Folders like "assets" and ".well-known" upload with their contents.)
  5. Click "Commit changes". The site updates in 1–2 minutes.
  Note: Windows may hide ".nojekyll" and ".well-known". In File Explorer click View > Show > Hidden items
  before Ctrl+A so they are included.
  Upload the new pages too: clubs-academies.html, lbw-rules.html, gully-cricket-rules.html.
  Old files (style.css and assets/logo.png, assets/favicon.png, assets/poster.jpg) are no longer used.
  You can leave them or delete them on GitHub.

OPTION B – NETLIFY
  1. Go to https://app.netlify.com/drop
  2. Drag the unzipped folder onto the page. Done.
  3. In Site settings > Domain management, add gullydrs.com.

AFTER IT'S LIVE (for SEO)
  1. Google Search Console (search.google.com/search-console): add gullydrs.com, then submit
     https://gullydrs.com/sitemap.xml
  2. Bing Webmaster Tools (bing.com/webmasters): import from Google Search Console
     (Bing also feeds ChatGPT search and Copilot).
  3. Test the structured data: https://search.google.com/test/rich-results  (enter gullydrs.com)
  4. Test the share preview: paste gullydrs.com into WhatsApp or https://www.opengraph.xyz
  5. Request indexing in Search Console for these pages first:
       https://gullydrs.com/lbw-rules.html
       https://gullydrs.com/clubs-academies.html
       https://gullydrs.com/gully-cricket-rules.html
  6. Share the LBW guide in cricket Facebook groups / Reddit (r/Cricket) when a big LBW controversy
     happens – that's when people search "umpire's call" and "lbw rules".
  7. When the app is live, send me the Google Play and App Store links and I'll add the
     "Get it on Google Play" / "Download on the App Store" buttons and update the structured data.
